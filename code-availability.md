# Code availability

## Summary

The source code for AADMN is **not included in this repository**. This is a deliberate
choice to protect the contribution prior to peer review and publication.

## What is and isn't here

**Included:** the complete method description, model specifications, hyperparameters,
configurations, results, summary result tables, and figures — everything needed to
*understand, evaluate, and verify* the work.

**Not included:** the runnable implementation — detector training, detection caching,
graph construction, the SceneGNN/SceneGAT re-scorers and training loop, efficiency
measurement, ONNX export, and figure-generation scripts.

## Release plan

The code will be released under an open-source licence **upon publication** of the
associated manuscript, at which point this statement and the repository
[LICENSE](../LICENSE) will be updated accordingly.

## Requesting access before publication

For peer review or verification, the code is available **from the author on reasonable
request**. Please include:

- your name and affiliation,
- the purpose of the request (e.g. review, replication, collaboration),
- agreement not to redistribute the code prior to publication.

Contact: **[your email / contact here]**.

## Why this approach

A public repository on a personal account cannot technically prevent forking. The robust
protection is therefore twofold:

1. **No runnable source in the repository** — there is nothing to copy-and-run.
2. **An "all rights reserved" licence** — copying or creating derivative works is not
   permitted without written consent.

This lets the project be presented as complete and credible while the contribution stays
protected until it is published.
